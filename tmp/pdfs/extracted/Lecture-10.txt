1.1 The Natural Progression
In our previous lectures, we learned how to:
•Summarizedata using measures of central tendency (Mean, Median, Mode)
•Describedata spread using measures of dispersion (Range, Variance, Standard
Deviation)
•Visualizedata using histograms and frequency distributions
But descriptive statistics only tells us aboutwhat has happenedin our collected
data. In Data Science and Artificial Intelligence, we need to answer questions about
what will happenin the future.

Real-World Applications in DS & AI
•Machine Learning Classifiers:
–A spam filter says: "There is a 98% probability this is spam"

–A fraud detection system says: "92% probability this transaction is fraud-
ulent"

–Netflix says: "You have a 90% chance of liking this movie"
–Amazon says: "You have a 75% chance of buying this product"

–"This is terrible" has 98% probability of being negative sentiment
•Computer Vision:
–The AI says: "95% probability this is a cat"
–"Face recognized with 99.5% probability"

The union of two sets A and B is the set of all elements that belong toeither A or B
(or both).

A set of events is collectively exhaustive if their union covers theentire sample space.
Collectively Exhaustive Events
Spam Classification:

5.3 Complementary Events
For any event A, its complement, denotedA′ orA c, is the event that "A does not occur."
Complementary Events
Machine Learning Classification:
•A = "Model prediction is correct"
•A’ = "Model prediction is incorrect"
•Together, they are mutually exclusive and collectively exhaustive
•Mathematically:A∩A ′ =∅andA∪A ′ =S
•Example:If the model has 95% accuracy, thenP(A) = 0.95andP(A ′) = 0.05

7 Fundamental Rules
7.1 The Complement Rule
P(A ′) = 1−P(A)
Complement Rule in AI
Model Accuracy:
•Let A = "Model makes correct prediction"
•If model has 96% accuracy:P(A) = 0.96
•ThenP(A ′) = 1−0.96 = 0.04
7.2 The General Addition Rule
P(A∪B) =P(A) +P(B)−P(A∩B)
General Addition Rule in AI
Multi-Label Classification:
•A = "Image contains a cat",P(A) = 0.60
•B = "Image contains a dog",P(B) = 0.45
•P(A∩B) = 0.20
P(A∪B) = 0.60 + 0.45−0.20 = 0.85
