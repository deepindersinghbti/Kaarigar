1 Mode: The Most Frequent Value
The mode is the value that appears most frequently in a dataset. Unlike mean and
median, the mode can be used with categorical data.
1.1 Why Mode Matters in CSE
Real-World Applications
•Error Analysis:Most common error code indicates the most frequent problem
•User Behavior:Most common user action helps in UI/UX design
•Caching:Most frequently accessed data should be cached
•Recommendation Systems:Most popular items to recommend
•Network Traffic:Most common packet size or protocol
•Database Queries:Most frequently executed query for optimization
1.2 Mode for Ungrouped Data
For ungrouped data, the mode is simply the value that occurs most frequently.
Finding Mode in Ungrouped Data
Example 1 (Single Mode):Data: 2, 3, 4, 5, 2, 3, 2
•2 occurs 3 times
•3 occurs 2 times
•4, 5 occur 1 time each
•Mode = 2
Example 2 (Multi-modal):Data: 1, 2, 2, 3, 3, 4
•2 occurs 2 times
•3 occurs 2 times
•Mode = 2 and 3(Bimodal)
Example 3 (No Mode):Data: 1, 2, 3, 4, 5
•All values occur once
•No mode exists
1.3 Mode for Discrete Grouped Data
For discrete grouped data, the mode is the value with the highest frequency.

1.4 Mode for Continuous Grouped Data
For continuous grouped data, we use the following formula:
Mode=L+ f1 −f 0
2f1 −f 0 −f 2
×h
Where:
•L= Lower limit of modal class
•f 1 = Frequency of modal class
•f 0 = Frequency of class before modal class
•f 2 = Frequency of class after modal class
•h= Class width
Mode in Continuous Grouped Data
Response times (in ms) of 50 network requests:

3 Why We Need Measures of Dispersion
Central tendency measures alone are insufficient. Consider this:
The Problem with Only Averages
Two datasets representing API response times (in ms):
Dataset A:100, 101, 102, 103, 104 (Mean = 102)
Dataset B:50, 75, 102, 129, 154 (Mean = 102)

Statistic Dataset A Dataset B
Mean 102 102
Median 102 102
Mode No mode No mode
Question:Are these datasets similar?
Answer:No! Dataset A is consistent (100-104 ms). Dataset B is highly variable
(50-154 ms).
This is why we needmeasures of dispersion- they tell us how spread out the
data is.
4 Types of Measures of Dispersion
Measures of dispersion are broadly classified into two categories:
4.1 1. Absolute Measures of Dispersion
Absolute measures are expressed in the same units as the original data. They
provide the actual spread of data.
Absolute Measures Include:
•Range- Maximum - Minimum
•Mean Deviation- Average of absolute deviations from mean
•Variance- Average of squared deviations from mean
•Standard Deviation- Square root of variance
•Quartile Deviation- (Q 3 - Q1)/2
4.2 2. Relative Measures of Dispersion
Relative measures are expressed as ratios or percentages. They allow comparison
between different datasets regardless of their units or magnitudes.
Relative Measures Include:
•Coefficient of Range- Range / (Max + Min)
•Coefficient of Mean Deviation- MD / Mean
•Coefficient of Variation (CV)- (SD / Mean)×100
•Coefficient of Quartile Deviation- (Q3 - Q1) / (Q3 + Q1)
Note: Absolute and Relative measures will be covered in detail in the next lecture.

5 Key Takeaways for CSE Students
•Mode:Only measure that works with categorical data; useful for finding most
common values
•Skewness:Important for choosing between mean and median
–Symmetric: Mean = Median = Mode
–Right-skewed: Mean > Median > Mode
–Left-skewed: Mean < Median < Mode
•Absolute Measures of Dispersion:
–Range: Simple but sensitive to outliers
–Mean Deviation: Easy to interpret but fails to distinguish extreme deviations
–Variance: Squared units, good mathematical properties
–Standard Deviation: Most widely used; penalizes extreme deviations
–Quartile Deviation: Robust to outliers
•Algorithm Complexity:
–Mode: O(N) time, O(N) memory
–Range: O(N) time, O(1) memory
–Mean Deviation: O(N) time, O(1) memory
–Standard Deviation: O(N) time, O(1) memory
–Quartile Deviation: O(N log N) time (sorting required)
Remember:
•Meanalone is not enough - always check spread!
•Skewnesstells you which average to use
•Modeis the only measure for categorical data
