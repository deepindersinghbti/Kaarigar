1 Weighted Mean: Why It Matters
In many real-world scenarios, not all data points are equally important. Theweighted
meanassigns different weights to different values, reflecting their relative importance.
1.1 The Problem with Simple A verages
Microservices Performance Monitoring
Consider a microservices architecture where:
•Service A handles 90% of API traffic with response time = 100ms
•Service B handles 10% of API traffic with response time = 500ms
Simple Arithmetic Mean:
100 + 500
2 = 300ms
Weighted Mean (User Experience):
0.9×100 + 0.1×500
0.9 + 0.1 = 90 + 50
1 = 140ms
The weighted mean (140ms) better represents the actual user experience because
90% of users experience 100ms response time.

Algorithm: Weighted Mean Calculation
def weighted_mean(values, weights):
if len(values) != len(weights):
raise ValueError("Values and weights must have same length")
total_weighted = sum(v * w for v, w in zip(values, weights))
total_weight = sum(weights)
return total_weighted / total_weight if total_weight != 0 else 0
# Example: API response times with traffic weights
response_times = [100, 500, 200]
traffic_weights = [0.9, 0.05, 0.05] # 90%, 5%, 5%
mean = weighted_mean(response_times, traffic_weights)
print(f"Weighted mean: {mean:.2f} ms") # Output: 135.00 ms

2.1 Why Classes with Matching Bounds Matter
In continuous data, class intervals are written as:
•Correct:0-10, 10-20, 20-30 (inclusive-exclusive)
•Correct:0 to less than 10, 10 to less than 20, 20 to less than 30
•Incorrect:0-10, 11-20, 21-30 (gaps between classes)
The upper bound of one class becomes the lower bound of the next class, ensuring no
gaps and no overlaps.

3 The Median: Why It Matters
The median is the middle value of a sorted dataset. It isrobustto outliers, making it
invaluable for real-world data.
3.1 The Problem with Mean and Outliers
Server Response Times with Network Spike
Consider server response times (in ms) for 10 requests:
100,102,101,100,103,102,101,100,102,10000
Mean:
100 + 102 + 101 + 100 + 103 + 102 + 101 + 100 + 102 + 10000
10 = 10911
10 = 1091.1ms
This mean is completely misleading - it suggests the server is slow!
Median:Sorted data: 100, 100, 100, 101, 101, 102, 102, 102, 103, 10000
Sincen= 10(even), median is average of 5th and 6th values:
Median= 101 + 102
2 = 101.5ms
The median (101.5ms) accurately represents the typical response time!
3.2 Why Median Matters in CSE
•Anomaly Detection:Median is robust to outliers in network monitoring
•Data Cleaning:Use median to impute missing values in skewed datasets
•Algorithm Performance:Median runtime is often more meaningful than mean
runtime
•Machine Learning:Median is used in tree-based models for splitting

Algorithm: Median for Ungrouped Data
def median_ungrouped(data):
sorted_data = sorted(data)
n = len(sorted_data)
if n % 2 == 1:
# Odd number of elements
return sorted_data[n // 2]
else:
# Even number of elements
mid = n // 2
return (sorted_data[mid - 1] + sorted_data[mid]) / 2
# Example
data = [100, 102, 101, 100, 103, 102, 101, 100, 102, 10000]
result = median_ungrouped(data)
print(f"Median: {result:.2f} ms") # Output: 101.50 ms

•Continuous Data with Matching Bounds:
–Class intervals must be mutually exclusive and exhaustive
–Example: 10-20, 20-30, 30-40 (inclusive-exclusive)
–Use mid-points as class representatives
–Remember it’s an estimate, not exact value
–All three methods (Direct, Short-cut, Step-deviation) yield the same result
•Median:Your best friend when dealing with outliers; robust to extreme values
•Coding Implementation:Always test your implementation with edge cases
(empty data, single value, etc.)
•Algorithm Choice:
–For small datasets: Direct methods are fine
–For large datasets: Use efficient sorting algorithms (O(nlogn))
–For streaming data: Use online algorithms withO(1)memory
–For distributed systems: Use approximate algorithms like t-digest for per-
centiles
Remember:The choice between mean, median, and percentiles depends on
your data and your requirements. For performance monitoring:
•Usemeanfor overall trend
•Usemedianfor typical case
•Useweighted meanwhen data points have different importance
